# Trilhas de fundo (opcional)

Coloque aqui arquivos reais com o nome do humor:

- `triste.mp3`
- `alegre.mp3`
- `epico.mp3`
- `suave.mp3`
- `suspense.mp3`

Formatos: `.mp3`, `.wav`, `.m4a` ou `.ogg`.

Se o arquivo existir, o app usa ele no lugar da música gerada.
Sugestão: baixe trilhas royalty-free (Mixkit, Pixabay Music, FreePD) e renomeie.
